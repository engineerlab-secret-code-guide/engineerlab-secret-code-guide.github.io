# 엔지니어랩 시크릿코드 가이드

GitHub Pages에서 별도 빌드 없이 작동하는 순수 정적 정보 사이트입니다.

## 배포 정보

- Organization: `engineerlab-secret-code-guide`
- Repository: `engineerlab-secret-code-guide.github.io`
- 예상 주소: `https://engineerlab-secret-code-guide.github.io/`

## GitHub 업로드

1. 위 이름으로 Organization과 Public Repository를 만듭니다.
2. ZIP의 압축을 푼 뒤 모든 파일을 저장소 최상단에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 배포 소스를 **Deploy from a branch**로 선택합니다.
4. Branch는 `main`, 폴더는 `/(root)`로 지정하고 저장합니다.

추가 빌드 명령이나 서버 설정은 필요하지 않습니다.
